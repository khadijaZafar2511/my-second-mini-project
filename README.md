# Interactive Box Playground

A lightweight web application built to practice and demonstrate advanced DOM manipulation and mouse event handling using Vanilla JavaScript.

## 🕹️ Interactive Features
*   **Box 1 (Randomizer)**: Generates and displays a random number on hover; restores original text when mouse leaves.
*   **Box 2 (Toggle State)**: Toggles its background color between red and green alternately on every hover.
*   **Box 3 (Dynamic RGB)**: Sets a completely randomized RGB background color on every hover.
*   **Box 4 (Master Controller)**: Changes the background colors of Boxes 1, 2, and 3 simultaneously upon clicking.

## 🛠️ Tech Stack
*   HTML5
*   CSS3 (Flexbox & Viewport Units)
*   JavaScript (ES6 Event Listeners)

## 💻 How to Run

